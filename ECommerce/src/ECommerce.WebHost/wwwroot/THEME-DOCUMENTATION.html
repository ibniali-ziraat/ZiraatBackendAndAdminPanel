🎨 Modern Theme Documentation

Comprehensive guide to the new modern, premium UI/UX theme for SimplCommerce with "Wow Factor" design.

📋 Overview

The modern theme features a contemporary design system built on glassmorphism, smooth animations, and a carefully curated color palette. It includes:

  • Modern Color System - Primary purples, secondary pinks, and elegant neutrals
  • Glassmorphism Effects - Frosted glass design with backdrop blur
  • Smooth Animations - 50+ built-in animations for engaging UX
  • Responsive Design - Mobile-first, fully optimized for all devices
  • Accessibility - WCAG compliant with dark mode support

🎨 Color Palette

The theme uses a carefully designed color system:

Color Variable Usage
Primary Gradient --gradient-primary Primary buttons, headings, accents
Secondary Gradient --gradient-secondary Highlights, badges, call-to-action
Primary Blue --color-primary Links, interactive elements
Success Green --color-success Positive actions, confirmations

⚙️ CSS Variables

All theme values are available as CSS variables for customization:

:root {
    /* Colors */
    --color-primary: #667eea;
    --color-secondary: #764ba2;
    --color-accent: #f5576c;
    
    /* Shadows */
    --shadow-md: 0 4px 6px -1px rgba(0, 0, 0, 0.1);
    --shadow-lg: 0 10px 15px -3px rgba(0, 0, 0, 0.1);
    
    /* Radius */
    --radius-lg: 1rem;
    --radius-xl: 1.5rem;
    
    /* Transitions */
    --transition-fast: all 0.2s ease-out;
    --transition-base: all 0.3s ease-out;
}

🌙 Dark Mode

The theme includes automatic dark mode support. Dark mode activates based on system preference:

@media (prefers-color-scheme: dark) {
    :root {
        --color-bg-primary: #1e293b;
        --color-text-primary: #f1f5f9;
    }
}

⚡ Performance Tips

  • Use .stagger-item for staggered animations in lists
  • Apply .skip-animation to elements that don't need animation
  • Leverage CSS variables for theme customization
  • Use prefers-reduced-motion for accessibility

🔧 Customization

To customize the theme, override CSS variables in your custom CSS file:

:root {
    --color-primary: #your-color;
    --gradient-primary: linear-gradient(135deg, #color1, #color2);
}
💡 Tip: All CSS files are included in the bundle configuration. No additional configuration needed - just start using the classes!
⚠️ Note: The theme is optimized for modern browsers. For IE11 support, use a CSS polyfill for CSS variables.
